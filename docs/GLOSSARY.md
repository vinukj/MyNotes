# MyNotes glossary

- **Note**: one top-level UTF-8 `.txt` file with an editable title (its filename) and body (its contents).
- **Library**: the main window where all notes can be browsed and searched.
- **Quick Notes**: the floating panel revealed from the top edge or by its menu command.
- **Notes Folder**: the local folder containing individual note files; optional clipboard history is in the separate `ClipboardHistory.store` database.
- **Top-edge gesture**: move the pointer to the screen's top edge, then scroll down.
