# MyNotes stories

## M1 Core notes

### S-001 Create a note
As the user, I create a note and begin typing immediately.
Screens: all-light.png, quick-notes-light.png
Acceptance:
- [self] Creating a note writes a plain-text file into the Notes Folder and selects it.
- [manual] Command-N creates a note from the library and quick-notes panel.
UX: Name the action “New Note”. Keep the title and body directly editable.
Status: todo

### S-002 Edit a note
As the user, I edit a note's title and body.
Screens: all-light.png, quick-notes-light.png
Acceptance:
- [self] Updated title and body remain in the `.txt` file after saving and reopening the app.
- [manual] The editor accepts multiline text without requiring a separate save action.
UX: Use a plain title field and a spacious body editor; autosave through SwiftData.
Status: todo

### S-003 Browse all notes
As the user, I browse all notes and select one to edit.
Screens: all-light.png
Acceptance:
- [snap] The library shows note titles in most-recently-edited order.
- [self] Selecting a note resolves the same stable note ID in the editor.
UX: Keep the library navigation simple: one All Notes page and a detail editor.
Status: todo

### S-004 Search note contents
As the user, I find a note by words in its title or body.
Screens: all-light.png, quick-notes-light.png
Acceptance:
- [unit] Search matches title and body without case sensitivity and an empty query matches all notes.
- [manual] Command-F focuses search in the library and quick-notes panel.
UX: Label the field “Search Notes”; show a clear empty-results state.
Status: todo

### S-005 Reveal quick notes from the top edge
As the user, I move the pointer to the top edge and scroll down to reveal quick notes.
Screens: quick-notes-light.png, quick-notes-dark.png
Acceptance:
- [manual] Pointer-at-top followed by a downward scroll reveals the floating panel over another app.
- [self] The panel controller can show and hide without creating duplicate panels.
- [manual] The gesture works without Accessibility or Input Monitoring permission.
UX: Reveal the panel without dismissing typed content. Keep a menu command and Command-Shift-N fallback.
Status: todo

### S-006 Choose where notes are stored
As the user, I choose a local folder for my plain-text notes.
Screens: settings-storage-light.png
Acceptance:
- [self] A newly selected folder becomes the active notes location.
- [manual] Settings shows the current folder and offers a folder picker.
- [manual] Existing top-level `.txt` notes appear without import and remain editable after quitting and reopening the app.
UX: Call the preference “Notes Folder”; explain that `.txt` files are the notes and the separate `.store` is only for clipboard history.
Status: todo

### S-007 Keep recent clipboard items
As the user, I keep copied text, images, and files nearby so I can restore them later.
Screens: quick-notes-light.png, settings-general-light.png
Acceptance:
- [self] Text copies are captured in the local store and duplicate copies do not create duplicate entries.
- [self] Restoring an item writes its contents back to a caller-selected pasteboard.
- [self] Marked-sensitive and password-manager copies are skipped.
- [self] Clipboard history can be cleared.
- [manual] Clipboard history starts disabled and can be enabled from Quick Notes or General Settings.
- [manual] Recent items appear in a horizontally scrollable shelf and can be restored or removed individually.
UX: Keep history on this Mac in the selected Notes Folder; limit it to 100 recent items and skip concealed, transient, autogenerated, and password-manager copies.
Status: todo

### S-008 Dismiss and configure Quick Notes
As the user, I dismiss Quick Notes by clicking outside and open storage settings from its small gear button.
Screens: quick-notes-light.png, quick-notes-dark.png, settings-storage-light.png
Acceptance:
- [manual] Quick Notes closes when it loses key focus, including an outside click.
- [manual] The gear opens Settings > Storage and the folder picker remains available.
- [snap] The translucent panel is nearly full display width and shorter than the main notes window.
UX: Use a compact icon-only gear with an accessible label and preserve the existing top-edge scroll-to-reveal gesture.
Status: todo

## Dropped
- iCloud sync, account sign-in, collaboration, attachments, tags, rich text, launch at login, and a customizable gesture.
